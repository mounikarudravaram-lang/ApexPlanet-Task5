
## Automated Data Analytics Pipeline

### Overview
This project uses Python and Pandas to automate the e-commerce data analysis process.

### Automation Tasks
1. Loads the cleaned e-commerce dataset.
2. Removes duplicate records.
3. Converts date and numerical columns into appropriate data types.
4. Calculates important business KPIs.
5. Generates monthly sales analysis.
6. Generates category-wise sales analysis.
7. Exports the cleaned dataset and analysis results as CSV files.

### Generated Output Files
- monthly_sales.csv
- category_sales.csv
- kpi_summary.csv
- automation_cleaned_data.csv

### How to Run
1. Install Pandas:
   pip install pandas

2. Run the automation script:
   py scripts/automation.py
